# 杭州人教版小学教材 · 知识点对齐口径

> 本文件是「以《杭州人教版小学》为准更新代码」这件事的**口径定义与裁决记录**。
> 目录里的多个数据源并不一致，直接拿其中任意一个去改 `data/topics.json` 都会改错。
> 复核工具：[`scripts/align_hangzhou.py`](../scripts/align_hangzhou.py)（只读）。

## 1. 四个来源与优先级

| 级别 | 来源 | 位置 | 权威性 | 已知问题 |
|---|---|---|---|---|
| **P1** | 教材 PDF 目录 | `杭州人教版小学/<科目>/教材/*.pdf` 的目录页 | **最高**：实物教材，教育部审定、出版社正式出版 | 部分旧课标版 PDF 是扫描件，目录页无文字层；语文/道法目录跨 2–4 页 |
| **P2** | 版本口径表 | `杭州人教版小学/教材清单.csv` | 高：决定每册该用「2022 课标修订版」还是「旧课标版」 | 只登记版本，不含章节 |
| **P3** | 配套学习材料目录树 | `杭州人教版小学/<科目>/学习材料/<册次>/<单元> - <课时>/` | 中：平台课时包落盘后的目录名 | 个别册次混有新旧两版目录（如科学一上同时有「植物/比较与测量」和「第一单元 周围的植物」） |
| **P4** | 平台原始课时树 | `杭州人教版小学/_build/docs_plan.json` | **最低**：构建期中间产物 | 科学的 `book.target` 指向**人教鄂教版**；数学四/五/六上的单元名仍是**旧课标版** |
| **T** | 代码章节树 | `code/data/topics.json` 的 `chapter` 字段 | 待校验对象 | — |

**裁决规则**

1. **P1 实物教材 PDF 目录是最终依据**。P4 与 P1 不同名时，一律不改代码。
2. **P2 决定版本**：标「2022 课标修订版」的册次按修订版目录核验；标「旧课标版」的册次说明修订版教材尚未发行，代码沿用现行目录属于合理取舍。
3. **P4 使用前必须校验 `book.target`**：若与 `教材清单.csv` 的 `相对路径` 不一致，说明该课时树属于另一套教材，**整册不可用作依据**。工具会自动列出这类错配。
4. **线上更新优先**：每轮先 `git fetch origin` 做 fast-forward 合入，再跑比对；不要用本地旧快照去覆盖线上新提交。
5. **有据可查的取舍不静默推翻**：代码里带 `standards[].note` 说明来源的知识点，即使与教材目录不符，也先记录、后确认，不直接删点（删点会连带影响题库与先修边）。

## 2. 已核实的证据（2026-11-05，直接读 PDF 原文）

- **数学四上**（`4年级上册（2022课标修订版）.pdf` p5 目录）：一 万以上数的认识 / 二 角的度量 / 三 多位数乘两位数 / 四 加法模型和乘法模型 / 五 平行四边形和梯形 / 六 条形统计图 / 七 复习与关联，另有「1亿有多大」「寻找宝藏」。**没有**「除数是两位数的除法」「数学广角——鸡兔同笼」。
- **英语三上**（p5 Contents）：`Unit 3 Our animal friends`（不是平台树的 `Amazing animals`）。
- **英语三下**（p5 Contents）：`Unit 2 My words and actions`、`Unit 3 Tools and senses for learning`、`Unit 5 Old things`（平台树分别是 `Expressing yourself`、`Learning better`、`Old toys`）。
- **英语四下**（p5 Contents）：`Unit 6 From farm to table`；**英语五上**：`Different friends / My feelings / Work and play / Healthy habits / Food we eat / Nature and us`。平台课时树缺五上、六上两册。
- **科学一上**（`05 科学（教科版）/教材/1年级上册（2022课标修订版）.pdf`，教育科学出版社，2024）：第一单元「周围的植物」、第二单元「我们自己」。与代码一致；平台树里的「走近科学/我们的感觉器官」属于人教鄂教版。

结论：**代码现有章节树与杭州目录里 2022 课标修订版教材 PDF 高度一致**；此前比对出现的「大量不一致」几乎全部来自 P4 平台课时树，属于版本错配，不是代码错误。

## 5. 已确认：数学四上 3 个知识点保留（2026-11-11 用户拍板 A）

**结论**：`cnm_p106` 除数是两位数的除法、`cnm_p107` 商不变的规律、`cnm_p131` 鸡兔同笼 **全部保留，不迁移、不删除**；`chapter`、题库、先修边、`confidence` 均不变，只在各自 `standards[0].note` 追加一句可见标注（图谱页与诊断页会渲染为「说明」）：

> 2026-11-05 已比对杭州《4年级上册（2022课标修订版）》教材 PDF 目录，该册无本单元；按 2026 秋教辅暂留，待修订版四下发行后复判。

`cnm_p131` 原有的「按 2026 秋教辅由四下迁入新版四上，待核」来源注记原样保留，新句追加在后，不覆盖。标注写在 `standards[].note` 而非 `chapter`，因此不改变命中工具的单元判定；`scripts/g4_grade_align.py` 只重写 `diagnostic_question` 与题库，不会覆盖该字段。

**决策依据**：`教材清单.csv` 明确四下仍是「旧课标版」，修订版四下尚未发行，现在无法确定这些点在新版教材中的最终归属；迁移或删除属于用不完整信息做不可逆决定，且会牵动 `dependencies.json`、`questions.json` 与 README 统计。

**当时评估过的方案**（存档，便于复判时回溯）：

| 方案 | 做法 | 影响 | 结果 |
|---|---|---|---|
| A 保留 + 标注 | 章节不变，仅在 `standards[].note` 与本文档记录差异及复判条件 | 零破坏；下一轮比对可识别为「已知例外」 | **已采用** |
| B 迁移 | 把 `cnm_p106/p107` 移到修订版四下（尚未发行）、`cnm_p131` 退回四下 | 需同步改依赖图、题库、生成脚本与统计，依据不足 | 未采用 |
| C 删除 | 从知识点、题库、先修边移除 | 破坏性最大，会丢失课标要求的「除数是两位数的除法」 | 未采用 |

**复判触发条件**：杭州目录出现「4年级下册（2022课标修订版）」教材 PDF，或 `教材清单.csv` 中四下的版本口径由「旧课标版」改为「2022 课标修订版」。届时重新读该册目录，确认这 3 个点的最终归属，再决定是否迁移；在此之前，比对工具应把这 3 项视为「已知例外」，不得因未命中而自动删除或改写章节。

## 6. 复跑方式

```bash
cd code
git fetch origin && git merge --ff-only origin/main     # 先与线上同步
python scripts/align_hangzhou.py                       # 生成 align-report.md
python scripts/align_hangzhou.py --json align-report.json
python scripts/validate.py                             # 数据自检
STRICT_STANDARDS=1 python scripts/validate.py          # 严格模式
```

- 默认杭州目录为仓库同级 `../杭州人教版小学`，可用 `--hangzhou` 指定其他位置。
- P1 依赖 PyMuPDF（`pymupdf`）；缺失时工具自动降级到 P3/P4 并在报告里标注置信度下降，也可显式 `--no-pdf`。
- 命中判定是**启发式**：把代码单元名（剥离「综合与实践」「第 N 单元」「Unit N」等前缀、拆分 `·`/`——`）归一化后，判断是否为教材目录页原文的子串。未命中不等于错误，需按第 3 节逐项裁决。
- `align-report.md` 是生成物，不入库。
